# Zahma – AI-Powered Crowd Density Mapping

## Overview
Zahma is a computer vision project designed to analyze crowd density and identify less crowded areas. The project aims to support crowd management and improve visitor flow in high-density environments.

## Objectives
- Analyze crowd scenes using computer vision.
- Detect people in video frames.
- Estimate crowd density and visualize spatial distribution.
- Identify potentially less crowded regions.

## Technologies
- Python
- YOLO11
- Computer Vision
- Object Detection
- Density Estimation
- Data Visualization

## Project Components
- Person detection and analysis.
- Crowd density visualization.
- Empty-region detection.

## Repository Contents
This repository contains selected project files and code related to crowd density analysis.
